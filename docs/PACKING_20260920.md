# 個人打包清單

使用者要求：「打包可以讓使用者自行新增分類跟項目，要容易使用。」保留正式預設清單與既有視覺，在打包頁加入個人清單操作。

## 操作

- 「新增分類」建立分類後，直接進入新增項目；每個既有分類也能新增項目。
- 按「加入」或 Enter 連續新增，按「完成」收起輸入區。中文選字時的 Enter 不送出表單。
- 「編輯清單」可以改名或移除自己新增的分類與項目；移除後可按「復原」，下一次清單變更會結束這次復原機會。
- 名稱去除前後空白，分類最多 32 字、項目最多 80 字；拒絕空白與同分類同名項目。
- 新增內容、勾選與改名立即存於目前瀏覽器。同瀏覽器、同網站的分頁會同步；換裝置或瀏覽器不共用，也沒有雲端備份。

## 實作契約

`PackingList.tsx` 只處理打包頁。`packingStorage.ts` 以 zod/mini 驗證版本、穩定 ID、名稱與布林勾選。預設 13 個項目和 ID 不變；`busan-pack-v2` 只保存個人內容與勾選，沒有 v2 或內容損壞時讀取 `busan-pack-v1` 可用布林勾選。載入不會立即回寫，舊鍵保留。

切換網站分頁不卸載清單，保留輸入草稿；儲存失敗會警示並留在記憶體。storage event 同步其他分頁更新，儲存前另外比對快照，避免事件尚未送達時以舊資料覆蓋；衝突時載入最新版、保留表單文字並請使用者再操作一次。此本機快照檢查不是跨程序交易鎖，也不提供跨裝置同步。

## 驗證

本機 `NODE_OPTIONS=--no-experimental-webstorage VITE_BASE_PATH=/busan-trip/ npm run check` 通過型別、lint、62 項測試、兩份資料驗證與正式建置。另用兩個同來源瀏覽器分頁驗證新增同步、保留輸入草稿、勾選雙向更新與重新整理保存；console error / warn 為空。獨立程式審查於多分頁防護補正後沒有 Important / Critical。

測試涵蓋舊勾選保留、新增與重載、連續新增和焦點、空白重名、改名後勾選保留、移除項目或分類與復原、中文輸入組字、儲存失敗、損壞紀錄、兩個分頁的舊資料覆蓋防護與草稿保留。

手機瀏覽器尺寸檢查使用 360 / 390px，並以 360 × 520px 短視窗檢查輸入表單。已修正連續新增時按鈕被底部選單遮住、完成新增後焦點跳回頁首兩個問題。這是瀏覽器視窗模擬，尚未完成真實 iPhone Safari 鍵盤或螢幕閱讀器驗收。正式檢查及上線結果記錄於 DEPLOYMENT.md。
