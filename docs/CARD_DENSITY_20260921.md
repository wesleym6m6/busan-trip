# 2026-09-21 卡片高度、圖片比例與航班文案修正

使用者指出初版加圖後卡片變高、空白過多，廣安里海邊圖仍像矩形插入；並要求移除哥哥續程卡片及說明、來回航班人數。調整中使用者補充：圖片應占更高比例，不能靠縮成難以辨識的小圖解決。

## 原因及現行配置

- 初版圖片在 `.trip-card-summary` 的 `flow-root` 中，84px 圖加 5px 底邊距，使原本只有 24.5px 的單行摘要占 89px。先前無重疊檢查沒有涵蓋與原版的高度差。
- 圖片現在置於整個 `.trip-card-heading` 的開頭，浮動於右側，與時間、標題、摘要共用高度。只有 heading 建立 `flow-root`；body 與摘要維持一般區塊，長文越過圖底即恢復全寬。
- 圖片一般為 80px；卡片寬度 ≤340px 使用 72px，≤290px 使用 64px，≥460px 使用 88px。沒有固定卡片高度或省略文字，也沒有新增圖片區塊下方的空白。
- 摘要回復加圖前的 14px／1.7 行高與 7px 上間距。標題維持 19px，使用 `text-wrap: pretty` 改善長標題斷行。地圖、詳情、停留預算保留完整寬度。
- 風景圖原先 `object-fit: contain` 在方框內形成寬幅實體圖邊緣，遮罩淡化的卻是方框留白。現以 `cover` 填滿遮罩區，再柔化所有邊緣；只改顯示裁切，原始圖片與公開副本未變。
- 載入失敗回復純文字、裝飾圖片無 accessible name、lazy loading 等行為仍保留。
